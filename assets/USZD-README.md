Para Realidad Aumentada en iPhone/iPad, el archivo AQUA_2040.usdz debe estar alojado en un lugar accesible públicamente por HTTPS. El archivo USDZ original de Meshy pesa aproximadamente 94 MB y no puede subirse mediante el navegador de GitHub (límite de 25 MiB). Además, Git LFS no sirve para entregar archivos desde GitHub Pages. Por ello, usar un USDZ optimizado por debajo de 25 MiB o alojarlo en un servicio/CDN compatible y actualizar ios-src en index.html.
