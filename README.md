# AQUA 2040

### Higiene inteligente. Un futuro más limpio.

AQUA 2040 es un concepto de taza sanitaria inteligente situado en el año 2040. La propuesta integra ahorro de agua, limpieza personalizada, autohigiene, sensores e interfaz mínima en un producto de estética futurista y funcional.

## Concepto

- **Descarga eficiente:** flujo optimizado para reducir el consumo de agua.
- **Limpieza personalizada:** higiene frontal y posterior con parámetros regulables.
- **Secado con aire:** reduce la dependencia de papel sanitario.
- **Autolimpieza:** rutinas automáticas para facilitar el mantenimiento.
- **Interfaz inteligente:** controles discretos para las funciones principales.
- **Diseño sostenible:** materiales durables y arquitectura orientada al mantenimiento.

## Sitio web

La landing page está construida como un sitio estático con HTML y CSS, sin dependencias de JavaScript, y está preparada para publicarse mediante **GitHub Pages**.

## Visión de diseño

AQUA 2040 busca demostrar cómo un producto cotidiano puede incorporar tecnología avanzada sin perder claridad de uso, ergonomía, higiene y responsabilidad ambiental.
